## Features
- Open original Clash .DAT save files
- Visual tile editor
- Tile inspector (raw binary editing)
- Unit editor
- Texture palette switching
- Squad management
- Binary patch saving
## Installation
- pip install -r requirements.txt
- python clash_editor
